## Problem 2

### Description

Find the last-but-one (or second-last) element of a Array/List.

### Example: Arrays

```purescript
> myButLast [1, 2, 3, 4] == 3
> myButLast ['x', 'y', 'z'] == 'y'
```

### Example: Linked Lists

```purescript
> myButLast (1:2:3:4:Nil) == 3
> myButLast ('x':'y':'z':Nil) == 'y'
```
